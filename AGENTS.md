# Kuroko

- Используйте Bun. Команды запуска и структура проекта описаны в [README.md](README.md).
- При изменении форматов запросов или ответов API обновляйте общие контракты в `packages/contracts/src`.
- После изменений в коде запускайте `bun run lint` и `bun run typecheck`. Для проверки поведения используйте `bun test`.
- Перед задачей по интерфейсу или изменениями в `apps/web` прочитайте [инструкции фронтенда](apps/web/AGENTS.md).
- Записывайте найденные баги, расхождения в документации и идеи для доработок в [BACKLOG.md](BACKLOG.md).
